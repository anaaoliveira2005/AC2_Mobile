# AC2 - Biblioteca de Livros

Aplicativo Android desenvolvido para a disciplina de Mobile.

## Descrição

Aplicativo para cadastrar e organizar livros que o usuário
deseja ler, está lendo ou já concluiu.

## Tecnologias utilizadas

- Android Studio
- Java
- XML
- Firebase Cloud Firestore
- RecyclerView

## Funcionalidades

- Cadastro de livros
- Listagem de livros
- Edição de livros
- Exclusão com confirmação
- Filtro por gênero
- Exibição da quantidade total de livros cadastrados
- Marcação de livros favoritos

## Banco de dados

Os dados são armazenados no Firebase Cloud Firestore,
garantindo a persistência dos registros.

## Como executar

1. Baixe ou clone este repositório.
2. Abra o projeto no Android Studio.
3. Confira a configuração do Firebase.
4. Sincronize o Gradle.
5. Execute o aplicativo em um dispositivo Android
   ou emulador.
